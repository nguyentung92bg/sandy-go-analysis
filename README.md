# Sandy Go! — Game Analysis

Mở index.html bằng Chrome hoặc Edge để đọc báo cáo ngoại tuyến.

Bản phân tích: Sandy Go! 0.12.0, package com.dino.sand.bus, ARM64.
Ngày báo cáo: 16/11/2026.

13 trang chính: Game Design, level, cơ chế, booster, kinh tế/quảng cáo, IAP, events, leaderboard, hằng ngày, Daily Challenge, quà mỗi ngày, analytics, nguồn. Phụ lục cấu hình và chỉ mục native được tách riêng.

Giá, phần thưởng và cổng tính năng là dữ liệu bản cài đặt, chưa xác nhận trạng thái live. Xem mục Nguồn & độ tin cậy trước khi sử dụng số liệu làm kết luận vận hành.
